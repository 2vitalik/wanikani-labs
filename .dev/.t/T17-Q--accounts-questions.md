# T17 · Питання до дизайну акаунтів (критичні позначено)

`2026-09-11` · ❓ question

Контекст:
- дизайн — [T14](T14-P--accounts-model.md), UX — [T15](T15-P--bot-ux-accounts.md), альтернативи з аргументами — [T16](T16-B--accounts-alternatives.md);
- ⭐ — критичні: без відповіді не стартую [T18](T18--accounts-v1/plan.md); решта — беру «рекомендую», якщо промовчиш.

**⭐ Q1 — Хто може стати користувачем бота?** (T16 §4)
- a) approve: `/start` → запит → тобі кнопки ✅/🚫 у `system` (рекомендую)
- b) open — будь-хто одразу активний
- c) closed — лише ти додаєш id через `/admin`
- d) invite-коди

> 

**⭐ Q2 — Токени в Mongo шифрувати Fernet-ключем з env (`WKLABS_SECRET_KEY`)?** (T16 §2) Наслідок: ще один секрет у `shared/env` і локальному `.env`; дамп бази без ключа — токени мертві.
- a) так, шифрувати (рекомендую)
- b) ні, відкритим текстом (Mongo з auth, localhost)

> 

**⭐ Q3 — Ключі акаунтів: `main`/`light` лишаються, нові — `wk_id[:8]`; на старті бот сам імпортує акаунти з `WK_TOKEN__*` у Mongo (власник — перший з `TG_ADMIN_IDS`), далі Mongo — істина?** (T16 §1, §7)
- a) так (рекомендую)
- b) імпорт лише руками `wklabs accounts import-env`
- c) інше (напиши)

> 

**⭐ Q4 — Фізичне видалення даних акаунта (purge) — лише CLI; у боті тільки «remove» зі збереженням даних?** (T16 §6)
- a) так, purge лише CLI (рекомендую)
- b) кнопка purge у боті з підтвердженням назвою

> 

**⭐ Q5 — Твоя доставка після переходу:** форум з `TG_FORUM_CHAT_ID` імпортується як чат `layout: topics`, маршрути `main`/`light` → топіки як планувалось, `subjects` і `system` — туди ж. Топіки ще не створені ні локально, ні (схоже) на vv3 — тож назви одразу можуть бути з `label`.
- a) так, і `label` для `main`/`light` = username WK (`Vitalik`, `2vitalik`) → топіки `📝 Vitalik · reviews` (рекомендую)
- b) так, але `label` = ключ (`main`, `light`) — як у [T02](T02-R--decisions-2026-08-23.md)
- c) інше

> 

**Q6 — Дефолт доставки для нового користувача — його приват з ботом; форум — через `/setup`?**
- a) так (рекомендую)
- b) без дефолту: після додавання акаунта одразу питати «сюди чи /setup у групі»

> 

**Q7 — Стан діалогів у памʼяті (`MemoryStorage`)?** (T16 §5)
- a) так (рекомендую)
- b) свій Mongo-storage

> 

**Q8 — `🗑 Remove` акаунта у форумі: топіки лишати?**
- a) лишати (рекомендую: історія повідомлень корисна; закрити можна руками)
- b) закривати (`close_forum_topic`), не видаляти
- c) видаляти топіки

> 

**Q9 — Той самий WK-акаунт від другої людини (друг із read-only токеном твого акаунта): зараз — відмова + сигнал тобі; шеринг (`viewer`) — пізніше. Ок?**
- a) так (рекомендую)
- b) дозволити одразу (друга людина стає `viewer`, отримує дайджести у свій чат)

> 

**Q10 — Мова текстів бота — EN (як зараз), UA — потім через i18n?**

- b) UA зараз, EN потім
