# T25 · Питання до дизайну чатів і доставки (критичні позначено)

`2026-09-12` · ❓ question

Контекст:
- дизайн — [T22](T22-P--chats-delivery-model.md), UX — [T23](T23-P--bot-ux-chats.md), варіанти — [T24](T24-B--chats-alternatives.md);
- ⭐ Q1–Q3 визначають форму фази 1; решту беру «рекомендую», якщо промовчиш.

**⭐ Q1 — Головний спосіб додати чат.** (T22 §1, T24 §1–2)
- a) нативний вибір чату (`➕ Add a chat` → Telegram-picker, бот додається з правами сам) + авто-реєстрація при ручному додаванні + `/setup` — усі три в один реєстр (рекомендую)
- b) без picker-а: лише авто-реєстрація + `/setup`

> 

**⭐ Q2 — Доля `/setup` у чаті.** (T23 §4, T24 §6)
- a) легкий: реєстрація, права, `📬 Deliver my digests here` + `⚙️ Configure in private`; повний редактор з галочками прибрати (рекомендую)
- b) лишити повний редактор як зараз, поряд із приватним UI
- c) прибрати `/setup` зовсім

> 

**⭐ Q3 — Хто може направляти доставку в чат.** (T22 §4, T24 §9)
- a) будь-який відомий учасник чату (бачив там / додав бота / вибрав picker-ом; інакше — жива перевірка членства); гілки перейменовувати — свої або адмін чату (рекомендую)
- b) лише адміни чату

> 

**Q4 — Розкладки форуму: додати «один топік на акаунт» (обидві категорії в одній гілці) до «топік на акаунт × категорію» і «без гілок»?** (T22 §1, T24 §5)
- a) так (рекомендую)
- b) ні, дві як є

> 

**Q5 — Операції з гілками з приватного UI.** (T22 §7)
- a) створити · перейменувати · вибрати наявну · General; без закриття й видалення (рекомендую)
- b) + закрити / відкрити
- c) + видалити (двокроково)

> 

**Q6 — Перші налаштування маршруту.** (T22 §3, T24 §8)
- a) `silent` (🔕 без звуку) + `items` для reviews (all / wrong only / counts only) (рекомендую)
- b) лише `silent`
- c) інший набір — напиши

> 

**Q7 — Спільна категорія `subjects` у спільному чаті.** (T22 §2, T24 §7)
- a) один маршрут на чат зі списком підписників; вимкнути = відписатись; налаштування спільні з позначкою «set by» (рекомендую)
- b) як зараз: один перемикач на чат, останній і вирішив

> 

**Q8 — Канали як ціль (single stream, право Post Messages).**
- a) так, дешево (рекомендую)
- b) ні, лише групи/форуми/приват

> 

**Q9 — Коли бота додали руками.** (T22 §6)
- a) DM тому, хто додав (якщо він уже писав боту), інакше один рядок у чат; раз на чат (рекомендую)
- b) мовчати, чекати `/setup` або `/chats`

> 

**Q10 — Дві фази реалізації (реєстр + picker + `/chats` + легкий `/setup` → вибір цілі + гілки + налаштування) чи одна задача?** (T22 §9)
- a) дві задачі, кожна лишає бота робочим (рекомендую)
- b) одна
