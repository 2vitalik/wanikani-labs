# T05 · Питання до конвенції комітів

`2026-09-10` · ❓ question

Контекст:
- пропозиція — [T04](T04-P--commit-convention.md); відповідь `>` після кожного питання.

**Q1 — Довжина заголовка.** Межа разом із суфіксом тікетів:
- a) ≤ 72 символи, ціль 50–60 — рекомендую (ліміт `git log --oneline` / GitHub без обрізання);
- b) ≤ 50 строго (класичне правило; з суфіксом тісно);
- c) інше.

> 

**Q2 — Тип для тестів.** Стандарт Conventional Commits — `test` (однина); ти казав `tests`:
- a) `test` — рекомендую (сумісно з commitlint та іншими тулами);
- b) `tests`.

> 

**Q3 — Scope.** `feat(bot): …` — вживати?
- a) необовʼязково, лише коли зміна в одному пакеті — рекомендую;
- b) завжди;
- c) ніколи.

> 

**Q4 — Кілька тікетів.** `t01-02` — перелік через дефіс, як у `vps-infra`; діапазонів не вводимо (`t03-05` = два тікети, не три):
- a) так, дефіс = перелік — рекомендую;
- b) кома без пробілу `t01,02` (у `vps-infra` теж траплялось).

> 

**Q5 — `.dev/`-зміни.** Тікети / README / CHANGELOG того ж рішення, що й код:
- a) в одному коміті з кодом, тип за кодом — рекомендую («чому» їде разом із «що»);
- b) завжди окремими `docs:` комітами.

> 

**Q6 — Трейлери агента.** `Co-Authored-By: Claude …` + `Claude-Session: …` у комітах, які роблю я:
- a) лишати — рекомендую (видно, що робив агент, є лінк на сесію);
- b) лише `Co-Authored-By`;
- c) прибрати.

> 

**Q7 — Де фіксуємо.** Після погодження:
- a) `.dev/README.md` (рядок «Коміти») + `CLAUDE.md` проєкту — рекомендую; глобальний `~/.claude/CLAUDE.md` `# git` правиш сам (або скажи «прав» — тоді я);
- b) лише проєктний `CLAUDE.md`;
- c) додатково commit-msg хук (commitlint / pre-commit), що валідує формат.

> 

**Q8 — Переписаний перший коміт.** Уже зробив `git commit --amend` (remote нема — безпечно) і закомітив переїзд і конвенцію за T04. Якщо правила зміняться — переписую всі три одним `git rebase --root`:
- a) ок, так і робимо — рекомендую;
- b) повернути старий заголовок першого коміту.
